# students_performance_analysis

This project analyzes student exam performance using Python and Pandas.

## Objectives:
- Understand student score distributions
- Analyze the impact of gender and test preparation
- Extract meaningful insights from data

## Tools Used:
- Python
- Pandas
- Matplotlib

## Key Insights:
- Students who completed the test preparation course performed better
- Reading scores are generally higher than math scores
- Minor differences observed between genders
